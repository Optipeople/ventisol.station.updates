# Ventisol station app releases

Installers and update packages for the Ventisol station app (MES-skærm). Binaries only: the source is private.

**[Download the latest installer (64-bit Windows)](https://github.com/Optipeople/ventisol.station.updates/releases/latest/download/VentisolStation-win-Setup.exe)**

**[Download the latest installer (32-bit Windows)](https://github.com/Optipeople/ventisol.station.updates/releases/latest/download/VentisolStation-win-x86-Setup.exe)**

Not sure which? Settings > System > About shows "32-bit operating system" or "64-bit operating system". On 32-bit Windows the 64-bit installer says "This app can't run on your PC".

Without installing: [64-bit portable](https://github.com/Optipeople/ventisol.station.updates/releases/latest/download/VentisolStation-win-Portable.zip) · [32-bit portable](https://github.com/Optipeople/ventisol.station.updates/releases/latest/download/VentisolStation-win-x86-Portable.zip)

Install once per PC. After that the app updates itself from this repo, each version from its own channel.
